# Getting Started

> Bu sayfa [İngilizce orijinalinin](../../Getting_Started/README.md)
> Türkçe çevirisidir. Kod ve dosya yolları İngilizce kalır; içerik farklılaşırsa
> İngilizce sürüm esas alınır.

Buradan başlayın. Bu kod tabanıyla ilgili deneyim gerekmez: bu bölümün sonunda yalnızca `Tiremo_Hal` kullanarak LED yakıp söndüren, UART üzerinden log basan, butonunu okuyan ve on LED'in hepsini süren bir kartınız olacak.

* **[Hello Blink](./01-Hello_Blink/)**: Karttaki bir LED'i yakıp söndürün; ilk başarılı derleme / yükleme turu.
* **[SysTick Timing](./02-SysTick_Timing/)**: Meşgul bekleme gecikmelerini milisaniyelik bir sayaçla değiştirin, böylece sonraki döngüler bloklamadan çalışabilsin.
* **[Debug UART Logging](./03-Debug_UART_Logging/)**: Seviyeli UART loglamasını devreye alın, böylece sonraki her eğitim ne yaptığını anlatabilsin.
* **[Button Read & Debounce](./04-Button_Read_And_Debounce/)**: USER butonunu yoklayın ve basma / bırakma / basılı tutma süresi olaylarını yazdırın.
* **[Ten-LED Pattern Driver](./05-Ten_LED_Pattern_Driver/)**: On LED'in hepsini sabit / yanıp sönen / nabız desenleriyle, bağımsız bir modül olarak sürün.
